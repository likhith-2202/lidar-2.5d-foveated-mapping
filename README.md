# Foveated 2.5D Semantic Mapping Engine

This module implements a variable‑resolution 2.5D semantic elevation map from classified LiDAR points.  
It is part of a larger autonomous navigation project (Person 2 module).

## Features
- Uniform 5 cm baseline map
- Distance‑based foveated grid (configurable resolution bands)
- Semantic aggregation (confidence‑weighted histograms)
- Elevation statistics (min, max, mean, variance)
- Occupancy (occupied / unknown)
- Risk‑aware refinement (optional)
- Benchmarking and performance measurement
- Adapter for SemanticKITTI data
